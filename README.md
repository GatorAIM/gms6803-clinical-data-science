# gms6803-clinical-data-science

This repository contains programming examples, lab materials, and supporting code for **GMS 6803: Data Science for Clinical Research**, offered by the Department of Health Outcomes & Biomedical Informatics at the University of Florida.

Course announcements, assignments, deadlines, and official course materials are available on **Canvas**.

## Repository Content

Materials in this repository will include examples and exercises related to:

- SQL and clinical data extraction
- Python and Jupyter Notebooks
- Data cleaning and preparation
- Data quality checks
- Exploratory data analysis
- Machine learning for clinical prediction
- Model interpretation

## Using the Repository

Students are encouraged to clone or download the repository and run the examples during and after class.
